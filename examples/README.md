# Exemplos

`gerar_segunda_via_demo.py` monta uma `DocumentacaoAcademicaRegistro` com o ramo `RegistroSegundaViaReq` usando dados fictícios e assinatura estrutural de desenvolvimento.

A assinatura do exemplo existe somente para exercitar o XSD. Rode com ambiente `Homologação` e não trate o arquivo como documento jurídico.

Para produção, substitua o mecanismo de assinatura pelo adaptador institucional e faça a validação XAdES/PBAD correspondente antes da publicação.
